気球・ロケットの落下地点予測の使い方と計算方法

SORAYOMIは、気球・ロケット・ロックーンが「どこまで上がり、どこに落ちるか」を、最新の気象予報から予測する無料のWebツールです。このページでは、使い方と、内部で行っている計算の考え方を説明します。

1. 成層圏気球の破裂高度と落下地点を予測する

ラテックス製の気象観測用気球（Totex・Hwoyeeなど）は、上空で周りの気圧が下がるにつれて膨らみ、メーカーが示す破裂直径に達したところで割れます。その後はパラシュートで降りてきます。上昇中も降下中も風に流されるため、落下地点は放球地点から数十〜200km以上離れることがあります。

使い方

  1. 「気球」タブを選び、地図をクリックするか地名で放球地点を指定します
  2. 放球の日時（現地時刻）を入れます。予報は最大16日先まで使えます
  3. 気球の種類、ペイロードの重さ、充填量（目標上昇速度・ネックリフト・ガス体積のどれか）、パラシュートの直径を入れます
  4. 「予測を実行」を押すと、軌跡・破裂高度・落下地点・落下範囲が表示されます

ネックリフトと上昇速度の関係

気球の口で測る持ち上げる力がネックリフトです。ネックリフトからペイロードの重さを引いた自由浮力が、空気抵抗とつり合う速さで気球は上がります。SORAYOMIは「目標上昇速度」を入れると、必要なネックリフトとガス量（m³）を逆算して表示します。たとえば1200gの気球に1kgのペイロードを付けて毎秒5mで上げる場合、ネックリフトは約2.3kg、破裂高度は約33kmになります（標準大気の場合）。

計算の考え方

  • 地上でのガスの量（質量）は変わらないとし、各高度の気圧・気温から気球の体積と直径を求めます
  • 直径が破裂直径に達した高度を破裂高度とします
  • 上昇速度は、実際の飛行データに近い「地上の速度を保つ」設定が標準です。理論どおり上空で速くなる設定も選べます
  • 降下速度は、パラシュートの直径と抗力係数から、各高度の空気の密度に応じた終端速度で計算します。上空ほど空気が薄いので速く落ちます

2. ロケットの最高高度と落下地点をシミュレーションする

モデルロケットやハイパワーロケットの飛行を、推力曲線と機体の形から計算します。

必要な情報

項目入力のしかた
推力平均推力と燃焼時間、または推力曲線ファイル（RASP形式 .eng。ThrustCurve.orgなどで入手できます）
質量モーターを除いた機体の質量と、モーターの全質量・推進剤質量
空気抵抗3Dモデル（STL）から自動推定、Cdを直接入力、またはOpenRocket・RASAeroのCd-マッハ数表（CSV）
発射条件ランチャーの長さ・仰角・方位
回収なし／一段開傘／二段開傘（ドローグ→メイン）、開傘のきっかけ（最高点・燃焼後の遅延・指定高度）

3Dモデルから抗力係数を推定する

STLファイルを読み込むと、全長・胴体径・ノーズの長さ・フィンの高さ・正面と側面の投影面積・表面積を自動で測ります。そこから、表面の摩擦抵抗、底面の抵抗、超音速でのノーズの造波抵抗、フィン前縁の抵抗を足し合わせて、マッハ数ごとの抗力係数（Cd）の表を作ります。精度の目安は±20%です。参考として、形状の重心と側面積の中心（簡易的な圧力中心）から安定余裕の目安も表示します。

計算の考え方

  • 回転する丸い地球の上での運動を計算します。高度による重力の弱まり、コリオリ力、地球の丸みを含みます
  • 機体は風上を向こうとする性質（風見安定）を持つとし、横風が強いと風上に向かって飛びます
  • ランチャーを離れる速度が毎秒15mより遅いと警告します
  • 開傘時の速度は、空気の薄さを考えた「海面相当の速度」で負荷を判断します

3. ロックーン（気球からのロケット打ち上げ）を計算する

ロックーンは、気球でロケットを高度30km前後まで吊り上げ、空気の薄い上空で点火する方式です。空気抵抗がほとんどなく、地上の発射場も要らないため、小さなロケットでも高度100kmの宇宙空間に届きやすくなります。1950年代のアメリカで観測ロケットとして使われ、現在も低コストな宇宙輸送の手段として研究されています。

SORAYOMIでは、気球の上昇と流され方 → 点火高度での浮遊 → 点火・燃焼 → 宇宙空間までの弾道飛行 → 再突入 → パラシュート回収までを一続きで計算します。高空ではノズルの外の気圧が低いぶん推力が増えるため、ノズル出口面積を入れるとその効果も含めます。再突入時に機体が横転して落ちる「タンブリング」も選べます。

4. ドローンを飛ばせるか風予報で判断する

ドローンの飛行で一番の問題になるのは風です。地上で弱い風でも、高度100mでは2倍近く強いことがあります。「ドローン」タブでは、地上10m・80m・120m・180mの予報から飛行高度の風を求め、突風率をかけて1時間ごとに判定します。

判定条件（標準設定）
中止突風が耐風性能を超える、1時間に0.2mm以上の降水、雷雨、動作温度の範囲外、視程1km未満
注意風が耐風性能の70%を超える、突風が80%を超える、降水確率40%以上、低温（バッテリー性能の低下）
飛行可上のどれにも当てはまらない

あわせて、国土地理院の人口集中地区（DID、令和2年）に入っているかを判定します。DID内での飛行には国の許可が必要です。空港周辺・高度150m以上・夜間・目視外などの規制は、国土交通省のドローン情報基盤システム（DIPS）で確認してください。

5. 予測の精度と落下範囲の見方

予報には誤差があり、気球の膨らみ方やロケットの推力にも個体差があります。SORAYOMIは、風の予報誤差（高度によって変わる誤差）と、ガス量・破裂直径・推力・抗力係数・質量・発射角などのばらつきを同時に与えて、標準で200回計算します（モンテカルロ法）。

  • 50%・95%・99%の楕円：その確率で落下点が入る範囲です。回収計画や落下区域の設定は95%以上の範囲を目安にしてください
  • CEP：落下点の半数が入る円の半径です
  • 海上に落ちる確率：落下点の標高から判定します

風の誤差は、打ち上げが1日先になるごとに25%大きくしています。予報は数時間ごとに更新されるため、直前にもう一度計算し直すのがおすすめです。

予測は参考値です。実際の放球・打ち上げでは、航空法に基づく許可・通報、落下区域の安全確保、関係機関への連絡を必ず行ってください。

6. よくある質問

気球の落下地点はどのくらい正確に予測できますか？

予報の典型的な誤差をもとにした計算では、放球の前日〜当日なら、落下地点の半数は予測点から飛行距離の5〜10%程度の範囲に入る見込みです。実際の飛行データでの検証はこれからです。風が強い日ほど流される距離が長く、誤差も大きくなります。

どの気象データを使っていますか？

米国海洋大気庁（NOAA）の全球予報モデルGFS（0.25°格子）を、Open-Meteoを通じて取得しています。地上から高度約31km（10hPa）まで28層の風と等圧面の高さを使い、緯度・経度・時刻・高度の4方向で補間します。31kmより上は米国標準大気で補います。

結果を保存できますか？

「データ出力」タブから、軌跡のCSV、モンテカルロの落下点CSV、Google Earthで立体表示できるKMLを保存できます。入力した条件はブラウザに自動保存され、JSONファイルにも書き出せます。

スマートフォンでも使えますか？

使えます。インストールは不要で、ページを開くだけで動きます。

料金や登録は必要ですか？

無料で、登録も不要です。ソースコードはGitHubで公開しています。

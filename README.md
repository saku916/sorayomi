# SORAYOMI 飛翔・落下予測

ドローン・気球・ロケット・ロックーンの飛行を、実際の気象予報を使って予測するWebアプリです。

**公開ページ：https://saku916.github.io/sorayomi/**

| モード | できること |
|---|---|
| ドローン | 飛行高度の風・突風・降水・気温・視程から、1時間ごとに「飛行可／注意／中止」を判定。人口集中地区（DID）の判定つき |
| 気球 | 上昇・破裂・パラシュート降下の軌跡と落下地点。ネックリフトやガス量も計算 |
| ロケット | 推力曲線と機体形状（3Dモデル）から軌跡・最高高度・最大動圧・落下地点を計算 |
| ロックーン | 気球で吊り上げて上空で点火する飛行全体（気球上昇→浮遊→点火→再突入→回収） |

気球・ロケット・ロックーンでは、モンテカルロ法（標準200回）で落下点のばらつきを計算し、50%・95%・99%の確率楕円と、海上に落ちる確率を示します。

## 起動方法

ブラウザで直接ファイルを開くと動きません（JavaScriptモジュールの制限）。次のコマンドで簡易サーバーを起動してください。

```bash
python serve.py
```

起動したら http://localhost:8765/ を開きます。インターネット接続が必要です（気象・標高・地図データを取得するため）。

## 使い方

1. 上のタブでモードを選ぶ
2. 地図をクリックするか、緯度経度・地名で発射地点を指定し、日時を入れる
3. 機体の条件を入れて「予測を実行」
4. 結果は「概要」「グラフ」「3D軌跡」に表示されます。「データ出力」から軌跡CSV・落下点CSV・KML（Google Earthで3D表示）を保存できます

入力内容はブラウザに自動で保存されます。「設定を保存／読込」でJSONファイルにも書き出せます。

### 3Dモデル（STL）

ロケットの「抗力係数の求め方」で「3Dモデル（STL）から推定」を選び、STLファイルを読み込みます。形状から全長・胴体径・ノーズ長・フィン高さ・投影面積・表面積を求め、Cd-マッハ数表を推定して計算に使います。「サンプル形状を使う」で動作を確認できます。

推定精度の目安は±20%です。OpenRocket・RASAero・風洞試験などで求めた表がある場合は「Cd-マッハ数表（CSV）」の方が正確です（1列目にマッハ数、2列目にCd）。

### 推力曲線

ThrustCurve.org などで配布されている RASP 形式（`.eng`）を読み込めます。ロックーンのように高空で点火する場合は、ノズル出口面積を入れると気圧が低いことによる推力の増加を計算に含めます。

## 計算方法

- **気象**：米国GFS（0.25°）の予報を Open-Meteo から取得。地表〜約31kmの28層の風と等圧面高度を、緯度・経度・時刻・高度で補間します。気温は等圧面の厚さから求めます。31kmより上は米国標準大気（1976）で外挿します
- **3段階の取得**：①発射地点だけで仮計算 → ②飛行範囲を覆う格子（最大25点）で再計算 → ③落下域の詳細な標高（15×15点＋軌跡直下）で着地点を決定
- **気球**：ガス量と各高度の気圧・気温から体積を求め、破裂直径に達した高度で破裂。上昇速度は標準では地上の値を保ちます（実測に近いため）。理論どおり変化させる設定もあります
- **ロケット**：回転する球体地球上の3自由度運動（重力の高度変化・コリオリ力・地球の曲率を含む）をRK4法で積分。風見安定・推力の偏心・タンブリング・二段開傘に対応
- **ばらつき**：風の予報誤差（高度方向に相関、1日先ごとに25%増し）と、ガス量・破裂直径・推力・Cd・質量・発射角・開傘タイミングの誤差を同時に与えます

## テスト

```bash
node --test tests/*.test.mjs
```

標準大気の値、真空中の到達高度（エネルギー保存）、コリオリ力による落下点のずれ（理論式）、終端速度、風による流され方、気球の破裂高度、3Dモデルの寸法・面積・体積などを確認しています。

## 限界と注意

- 姿勢の回転運動（6自由度）、多段式ロケット、局地的な地形風・乱流、気球の過圧・放熱は扱っていません
- 気象APIは無料枠（1分あたりの回数制限あり）を使っています。続けて何度も実行すると制限にかかることがあります。商用利用には Open-Meteo の有料プランか、自前でGFSデータを取得する仕組みが必要です
- 気球のプリセットの破裂直径は代表値です。実際の値はメーカーのデータシートで確認してください
- 予測は参考値です。実際の打ち上げでは航空法に基づく許可・通報、落下区域の安全確保を必ず行ってください

## データの出典

- 気象予報：[Open-Meteo](https://open-meteo.com/)（NOAA GFS）
- 標高：Open-Meteo Elevation API（Copernicus DEM）
- 地図・人口集中地区・住所検索：[国土地理院](https://maps.gsi.go.jp/development/ichiran.html)
